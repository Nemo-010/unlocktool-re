# OEM / device compatibility matrix

Generated by `scripts/build_matrix.py` from the shipped `data/` tree.
Every column is a measurement, not a claim: `advertised` counts `<program>`
rows in the brand index, `folder` counts directories that actually exist,
`loader ok` counts `programs.bin` files that decrypt to an ELF with the
recovered key, and the operation columns count scripts that parse.

A device is only usable end-to-end when `folder` and `loader ok` are both
set and at least one operation script parses. Devices that are advertised
but have no folder are visible in the UI and then fail, which is the
behaviour the vendor README itself describes.
